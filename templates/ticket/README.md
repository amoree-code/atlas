# Ticket template

Copy this directory to `projects/<project>/tickets/<ticket-id>/` to start a new ticket,
replacing the placeholders in `task.md`.

`task.md` is the **only** mandatory file — everything else is an artifact, created on
demand once it's actually needed (see `schemas/task.md` §5, "No artifact is scaffolded.
Ever."). Do not pre-create empty `decisions.md`, `checkpoint.md` or similar files
alongside it.

See a worked, fully filled-in example at
`docs/examples/project/a-project/tickets/EXMPL-001/task.md`.
