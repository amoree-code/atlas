# Project template

Copy this directory to `projects/<project>/` to start a new project, replacing
`<project>` throughout — and add a row for it to `projects/registry.md`.

```
projects/<project>/
  index.md       the work board — ticket table regenerated by `ai-os tickets index --write`
  context/       durable narrative context — copy templates/context/ here and fill it in
  tickets/       one directory per ticket — copy templates/ticket/ here per new ticket
```

`index.md` ships with the `<!-- ai-os:tickets:begin -->` / `<!-- ai-os:tickets:end -->`
markers already in place around an empty table — `ai-os tickets index --write` refuses to
regenerate a board that doesn't have them, so leave them exactly as they are and let the
tool fill in the rows once a real ticket exists under `tickets/`.

See a worked, fully filled-in example at `docs/examples/project/a-project/`.
