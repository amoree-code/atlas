# Session handoff

Create a portable continuation packet, not a transcript.

Include the project and ticket, one-line objective, verified results, important decisions,
changed paths, blockers, the next concrete action, and exact verification commands. Point to
durable files instead of copying their contents. Never include credentials, tokens, cookies,
private documents, or unnecessary session identifiers.
